# SA-Copilot

Локальный помощник системного аналитика для подготовки и проверки:
- технических заданий;
- функциональных и нефункциональных требований;
- бизнес-правил;
- критериев приёмки;
- тест-кейсов;
- открытых вопросов и предположений.

## Технологии

- Python 3.13+
- Ollama
- Qwen3 8B
- HTML, CSS, JavaScript
- Git

Приложение работает локально, без платных API.

## Установка на новом компьютере

1. Установить Git.
2. Установить Python 3.13 или новее.
3. Установить Ollama.
4. Скачать модель:

   ollama pull qwen3:8b

5. Клонировать репозиторий:

   git clone https://github.com/DmitriyVolkov154/SA-Copilot.git

6. Перейти в папку:

   cd SA-Copilot

7. Создать виртуальное окружение:

   py -3.13 -m venv .venv

8. Запустить тесты:

   .\.venv\Scripts\python.exe -m unittest discover -s tests -v

9. Запустить приложение:

   .\.venv\Scripts\python.exe app.py

10. Открыть в браузере:

    http://127.0.0.1:8000

Отдельный requirements.txt пока не требуется:
текущая версия использует стандартную библиотеку Python.

## Работа с нескольких компьютеров

Перед началом работы:

    git pull origin main

После завершения изменений:

    git add .
    git commit -m "Описание изменений"
    git push origin main

Не переносить папку .venv между компьютерами.
Она создаётся отдельно на каждом устройстве.

## Структура проекта

- app.py — сервер и взаимодействие с Ollama
- validator.py — проверки результата
- tests/ — автоматические тесты
- templates/ — HTML
- static/ — CSS и JavaScript

## Ограничения

Валидатор использует эвристические проверки.
Он помогает находить отдельные противоречия и неподтверждённые условия,
но не заменяет экспертную проверку системного аналитика.
